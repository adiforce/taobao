# 淘寶代購管理

Google Sheet 搭配 Apps Script 網頁應用程式，用來記錄淘寶代購、集運運費分攤、各人結算與付款。

## 檔案
- `apps-script/Code.gs`：後端，讀寫試算表（只寫輸入欄，計算欄全由試算表公式負責）。
- `apps-script/Index.html`：網頁介面。
- `apps-script/appsscript.json`：時區 Asia/Taipei、僅限本人存取。

## 試算表分頁（需先存在）
| 分頁 | 輸入欄 | 計算欄 |
|---|---|---|
| 訂單 | A 編號、B 下單日、C 品名、D 運單、E 重量kg、F WHO、G 商品¥、H 匯率、I 集運批次、J 狀態、K 備註、T 淘寶訂單號 | L–S（手續費、台幣、運費占比與分攤、總額、重複運單） |
| 運費批次 | A 批次、B 日期、C 計費kg、D 單價、E 運費¥、F 匯率、G 貨態連結、H 備註、O 收件地址 | I–N |
| 付款紀錄 | A 日期、B WHO、C 金額、D 方式、E 對應批次、F 備註 | — |
| 結算 | — | 全部為公式 |
| 設定 | 費率、代墊人、匯率來源、人員／狀態／付款方式清單 | — |

## 部署
1. 從試算表開「擴充功能 → Apps Script」（容器綁定），或另開獨立專案並在 `Code.gs` 的 `SS_ID` 填入試算表 ID。
2. 貼上 `Code.gs`，新增名為 `Index` 的 HTML 檔並貼上 `Index.html`。
3. 部署 → 網頁應用程式 → 執行身分「我」、存取權「只有我」，首次需授權（抓匯率會連外）。

## 登入
網頁需先輸入密碼：`Code.gs` 的 `PW_PREFIX` + 台北時間 `MMddHH`（月日時），整點前後一小時內有效；連錯 5 次鎖 10 分鐘。登入後取得 6 小時有效的 token，所有資料操作都經過 `api()` 驗證。`PW_PREFIX` 請在部署時自行填入，不要提交到公開 repo。

## 功能
訂單輸入（重量可先空白）、依重量分攤集運運費、批次指派／補重量／拆單、各人應付與未付、付款紀錄、貨態連結、重複運單標記、集運出貨資訊產生、自動取得臺灣銀行牌告人民幣匯率。
